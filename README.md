# 6Doku

A dual-format 6×6 Sudoku game for **iOS 17** and **watchOS 10**, built with SwiftUI on a shared puzzle engine with CloudKit sync.

Two valid region layouts: **2×3 boxes** (default) and **3×2 boxes** — standard Sudoku rules, quick-play sized.

## Features

- 6×6 Sudoku in both formats, 3 difficulties, unique-solution generation
- 48-puzzle bundled seed catalog with CloudKit public-catalog fetch + offline fallback
- 6 readability grid themes (Classic, Midnight, High Contrast, Volt, Ember, Cobalt) — picked on iPhone, synced to watch via iCloud
- Watch-first input: full-page number picker, high-contrast givens, subtle haptics
- Progress + stats sync across devices (private CloudKit DB, offline queue)
- VoiceOver support per UI spec (labeled cells, move announcements)

## Architecture

```
SharedCore/       Models + engine (Solver, Generator, Validator, BoxMapping, HintEngine, AppTheme)
SharedServices/   CloudKitService, SyncManager, PersistenceService, SettingsService, ThemeManager, HapticsService
iOSApp/           Home, Library, Puzzle, Stats, Settings (+ grid/number-pad components)
WatchApp/         Home, puzzle grid, number picker page
SixDokuTests/     Engine + sync + theme suites (Swift Testing)
Tools/            SeedGenerator (catalog JSON), MakeIcon (AppIcon PNG)
```

Single Xcode project generated by **xcodegen** from `project.yml`. `SharedCore`/`SharedServices` are multi-destination (`iOS` + `watchOS`) frameworks.

## Requirements

- Xcode 26+, iOS 17+ / watchOS 10+
- [xcodegen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`)
- Apple Developer team for device builds + CloudKit (Dev container `iCloud.com.sixdoku.dev`)

## Getting started

```bash
xcodegen generate          # regenerate SixDoku.xcodeproj (required after adding files)
swift test                 # 23 tests, 7 suites
xcodebuild -scheme SixDoku -destination 'platform=iOS Simulator,name=iPhone 17' build
```

Open `SixDoku.xcodeproj`, select your team under Signing & Capabilities (persists via `project.yml`), then run the `SixDoku` or `SixDokuWatch` scheme. Note: install watch builds via **Xcode Run** on your physical watch — sideloaded `devicectl` installs get reconciled away by the paired iPhone.

### Seed catalog

```bash
./scripts/seed-catalog.sh [perBucket=8]   # regenerates bundled SeedCatalog.json (iOS + watch)
```

Or seed the CloudKit public DB from a signed-in device: Settings → Seed Catalog to iCloud.

## CloudKit

- Public DB: `PuzzleCatalog` (puzzleID, format, difficulty, initialClues, solutionGrid, createdAt, version)
- Private DB: `PuzzleState`, `UserStats` (dTournaments JSON-encoded `bestTimes`/`formatUsage`, `themePreference`)
- Remember to **deploy the schema to Production** before external TestFlight testers go in.
